# Appointment Lookup

A web application for viewing and managing appointment data using Google Sheets as a lightweight backend.

---

## Features
- Patients can check their appointment schedule 24/7.

---

## Tech Stack
- Next.js
- Google Sheets API (or CSV-based data source)
- CSS Modules


---

## How to Use

1. Clone the repository

```bash
git clone https://github.com/ratchanon-noknoy2318/appointment_website.git
npm install
npm run dev
```
2. Open http://localhost:3000 to access the registration system.
3. Create a .env file in the project root and configure the following variables:
```bash
   GOOGLE_SHEET_ID=your_google_sheets_id
```
